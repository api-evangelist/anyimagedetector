# AnyImageDetector

A single-purpose AI-image-detection service. The AI Image Detector API exposes a single REST endpoint that reports whether an image is AI-generated, returning a verdict, a probability score, a confidence level, and an optional per-generator breakdown.

## APIs

- **AI Image Detector API** — REST API with a single endpoint (POST /v1/image/detect) that detects whether an image is AI-generated. Accepts a multipart file upload or a JSON body with a public image URL, and returns verdict, ai_score, confidence, and source_breakdown. Requires a paid account and Bearer/x-api-key authentication. (`https://imagedetector.online/v1`)
